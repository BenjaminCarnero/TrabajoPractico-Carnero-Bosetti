## Cómo levantar el sistema desde cero

1. Ejecutar `script.sql` en SQL Server.
2. `cd back` y `npm install`
3. Copiar `back/env.ejemplo` como `back/.env` y completar los valores.
4. `npm start`
5. Abrir http://localhost:3000
